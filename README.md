# 📈 A股情绪择时模型 — 从涨跌停板到市场情绪的量化策略

> 基于涨跌停板数据构建市场情绪因子，结合传统机器学习与 DQN 强化学习生成情绪得分，驱动 A 股周度择时策略。

## 项目概述

本项目复现并扩展了国泰海通证券研报《从涨停板、"打板策略"到赚钱效应引发的情绪择时指标》（2025.05.14）的核心思路，将研报中基于规则的情绪择时模型升级为**数据驱动的机器学习 + 强化学习框架**。

核心假设：涨跌停板不仅反映个股强弱，更是市场情绪高涨、资金活跃的重要标志。当追涨/低吸策略的投资者较多且能够获利时，往往意味着市场整体情绪偏向乐观。

## 因子体系

| 因子名称 | 计算方式 | 预期方向 |
|---------|---------|---------|
| 涨停占比 | 涨停股数量 / 总股票数量 | 正向（越高越乐观） |
| 跌停占比 | 跌停股数量 / 总股票数量 | 反向（越高越悲观） |
| 净涨停占比 | 涨停占比 − 跌停占比 | 正向 |
| 打板收益 | 涨停股次日平均收益（缩尾处理） | 正向 |
| 跌停收益 | 跌停股次日平均收益 | 正向（亏损减少→情绪好） |
| 市场收益 | 全市场个股平均涨跌幅 | 目标变量 |

每个因子还额外计算 lag1、lag2 滞后特征，供模型捕捉动量效应。

## DQN 强化学习模块

`sentiment_dqn.py` 中的 `DQNSentimentModel` 将情绪择时建模为一个序贯决策问题：

- **状态空间**：增强特征集（原始因子 + 滞后 + 滚动统计 + Z-score + 趋势 + 交互特征）
- **动作空间**：5 档仓位（-2, -1, 0, +1, +2），对应做空到满仓做多
- **奖励函数**：仓位收益 − 交易成本 − 风险惩罚 − 回撤惩罚
- **网络结构**：3 层全连接（512→256→128）+ Dropout(0.2) + Double DQN
- **情绪得分生成**：最优动作 Q 值 → tanh 归一化 → 乘以 softmax 置信度 → 5 日滚动平滑

## 快速开始

### 环境要求

```bash
pip install pandas numpy matplotlib seaborn scikit-learn tensorflow openpyxl scipy
# v2.0 额外需要
pip install torch
```

### 运行

```bash
# 将数据文件放入 ../data/ 目录
# v1.0（仅传统模型）
python main.py

# v2.0（传统 + DQN 对比）
python main2_0.py
```

### 数据格式要求

Excel 文件格式：行索引为 `日期`（交易日），列为个股代码，值为对应的涨跌幅（%）/ 开盘价 / 收盘价。涨停判定阈值为 ±9.9%。

## 研报核心结论（参考基准）

研报回测区间 2010.01–2025.04，以 Wind 全 A 指数为标的：

| 模型版本 | 年化收益 | 年化波动 | 最大回撤 |
|---------|---------|---------|---------|
| 基础模型（五因子等权） | 6.65% | 15.37% | 29.39% |
| +市场趋势判断 | 9.41% | 17.98% | 46.35% |
| +因子信号加权 | 9.68% | 13.31% | 24.47% |
| Wind 全 A 基准 | 3.82% | 22.40% | 55.08% |

本项目的 ML/DQN 模型旨在探索是否能通过数据驱动方式进一步提升信号质量。

## 风险提示

- 回测结果不代表未来表现，存在过拟合风险
- 市场系统性风险、流动性风险、政策变动风险
- 因子可能随市场结构变化而失效
- DQN 模型对超参数敏感，需充分调优与样本外验证
